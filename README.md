# U50 家庭资料库地图：先识别，再预览归档与提醒

本教程用一组完全虚构、仅含模拟文件名和示例日期的家庭资料清单，示范如何制作资料库地图。素材不含真实证件号、账号、地址、合同正文或付款信息。重点是识别资料类型、使用风险标签、发现版本与日期问题、预览整理方案，并只为有来源的到期信息设置提醒。

## 文件地图

- `materials/`：虚构资料清单 CSV、已替代旧版、重复件、未核实便签、模拟敏感文件说明和错误 AI 草稿。
- `tutorial/家庭资料归档实操教程.md`：五步实践教程。
- `reference/资料地图参考答案与陷阱核验.md`：逐项核验版本、日期、重复项、缺项和访问边界。
- `templates/家庭资料归档提示词模板.md`：可复用提示词。
- `results/家庭资料库地图参考.csv`：本练习最终地图草案。

## 重要边界

文件名中的“合同有效期/保修到期”与法律要求的资料保存年限是不同问题。此示例不判定合同效力、税务/法律留存期限、销毁时间，也不自动迁移或删除文件。真实证件、金融账户、医疗信息、行踪等敏感内容不要直接上传到 AI；先确认处理目的、必要性、授权和适用要求，并使用脱敏后的最少字段。

《中华人民共和国个人信息保护法》第二十八至三十条对敏感个人信息的范围和处理要求作了规定。请查看[全国网信办发布的法律全文](https://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm)，并由有权人员依据具体场景判断适用性。
